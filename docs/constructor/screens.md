## 1. Главная

### Назначение

Показать рабочую ситуацию без просмотра всех баз.

### Блоки

- быстрые кнопки четырёх основных режимов.

- устаревшие источники.

## Адаптация под мобильный экран

Мобильная версия нужна не для полного редактирования базы, а для работы во время переписки.

Приоритетные мобильные режимы:

- быстрый ответ на вопрос клиента;
- просмотр карточки клиента;
- следующий контакт;
- диагностика;
- копирование сценария;
- добавление заметки.

Полные таблицы, импорт и редактор схемы остаются оптимизированными для десктопа.
