# Русский текст сайта

Переведены английские подписи во всех секциях, карточках, панели направлений, тегах экспертизы, контактах, сноске и поисковых метаданных. AI → ИИ; Creative OS → направления работы; Selected Projects → избранные проекты; PRIVATE → закрытый доступ; Email → почта. Латинское написание имени заменено русским. PDF в описании услуг заменён электронными документами/руководствами.

Адреса ссылок, электронная почта, имена аккаунтов, фирменная монограмма JS и программные идентификаторы сохранены. В сноске название компании передано кириллицей: «Мета Платформс Инк.»; содержание существующей сноски сохранено.

Существующие проверки title и закрытого доступа обновлены под русский текст. Проверка: npm run lint; npm test (включает npm run build).
